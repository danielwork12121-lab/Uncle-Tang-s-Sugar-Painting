# 甜叔糖画铺 / Uncle Tian's Sugaria

A browser-based interactive game preserving the traditional Chinese folk craft of sugar painting (糖画). Built with HTML5 Canvas and Vite.

**Tencent "AI Can Do It" Game Development Challenge — regional top-18 team (of 2,589), advanced to the finals.**

I built the frontend and backend game systems — scene management, mini-game logic, and the Vercel deployment pipeline — working with a UI/UX designer to translate concepts into production features.

**Play Online**: https://uncletian.xyz

## Features

- **Story-driven experience**: Follow Uncle Tian through the sugar painting process
- **Multiple cutscenes**: Professional animated videos
- **Interactive mini-games**:
- Scene 2: Sugar cooking simulation
- Scene 3: Candy spreading/pouring
- Scene 5: Circle candy drawing (practice + real order)
- Scene 7: Dragon candy drawing (advanced)
- **Chinese UI and cultural details**: Authentic sugar painting facts and terminology
- **Web deployment**: Custom domain with Vercel auto-deployment
